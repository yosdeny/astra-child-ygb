== Description ==

Astra Child theme based on the popular Astra parent theme. Lightning-fast and highly customizable.

== Installation ==

1. Upload the theme folder to `/wp-content/themes/`
2. Activate the theme through the 'Themes' menu in WordPress
3. Make sure the Astra parent theme is installed and activated
